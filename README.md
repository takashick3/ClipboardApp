# ClipboardApp

macOS 用の軽量クリップボード履歴管理アプリです。

## 機能

- **クリップボード履歴** — コピーした内容を自動的に記録（最大50件保存、表示件数は設定で変更可）
- **重複排除** — 同じ内容をコピーすると履歴の先頭に移動（重複しない）
- **RTF / RTFD 対応** — Teams・Slack などからコピーしたテキストも記録
- **ピン留め** — よく使う履歴をピン留め・ドラッグ&ドロップで並び替え
- **スニペット** — よく使うテキストをフォルダ管理、Clipy互換XMLでエクスポート/インポート
- **グローバルショートカット** — どのアプリからでも呼び出し可能
- **キーボード操作** — ポップアップ内を↑↓で移動、←→でタブ切り替え、Enterで貼り付け
- **カスタマイズ** — ウィンドウ幅・最大高さ・文字サイズ・履歴件数を設定可能
- **ログイン時に自動起動**

## ショートカット

| キー | 動作 |
|------|------|
| ⌘ + Shift + V | 履歴ポップアップを開く |
| ⌘ + Shift + B | スニペットポップアップを開く |
| ↑ / ↓ | 項目を選択 |
| ← / → | タブ切り替え・スニペットフォルダを開く/閉じる |
| Enter | 選択した内容を貼り付け |
| Esc | ポップアップを閉じる |

## 動作環境

- macOS 13 Ventura 以降
- Apple Silicon / Intel 両対応

## インストール

1. [Releases](https://github.com/takashick3/ClipboardApp/releases) から最新の `ClipboardApp-x.x.x.dmg` をダウンロード
2. DMG を開いて `ClipboardApp.app` を Applications フォルダにドラッグ
3. アプリをダブルクリック → 「"ClipboardApp" は開いていません」と表示されたら「完了」をクリック
4. **システム設定 → プライバシーとセキュリティ** を開き、下部に表示される「このまま開く」をクリック
5. アプリが起動したら「**続ける**」→「**システム設定を開く**」の順にクリック
6. **アクセシビリティ**の一覧に追加された ClipboardApp を **ON** にする
7. アプリを再起動して完了

> **Note**  
> 手順 3〜6 は初回のみ必要です。2 回目以降は普通にダブルクリックで起動できます。

## アップデート / 入れ直し

新しいバージョンをインストールする際は、アクセシビリティ権限の再許可が必要です。

1. 古い `ClipboardApp.app` をゴミ箱に捨てる
2. 新しい DMG から `ClipboardApp.app` を Applications フォルダにドラッグ
3. インストールと同じ手順 3〜7 を繰り返す

> **Note**  
> アクセシビリティ権限の再許可が必要なのは、現在のビルドが開発者署名なし（ad-hoc 署名）のため、  
> バージョンが変わると macOS が別のアプリと判断するためです。
